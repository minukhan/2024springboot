# 🌟 **2024 오토에버스쿨 Spring Boot 학습 및 실습** 🌟  

---

## 📚 **프로젝트 개요**  
이 저장소는 **Spring Boot**를 활용하여 **백엔드 개발 역량**을 키우기 위해 설계되었습니다.  
RESTful API 개발, 데이터베이스 연동, 보안 설정 등 **핵심 백엔드 기술**을 실습을 통해 체계적으로 학습하였습니다.  

---

## 🚀 **학습한 기술 스택**  

| **기술**       | **설명**                            |
|---------------|------------------------------------|
| 🛠️ **Spring Boot** | 빠르고 효율적인 애플리케이션 개발 프레임워크 |
| 🗄️ **JPA**         | 객체지향적으로 데이터베이스와 상호작용     |
| 📊 **MyBatis**     | SQL 기반의 데이터 매핑 및 제어           |
| 🔐 **Spring Security** | 인증 및 권한 관리로 안전한 시스템 구축      |
| 📦 **Docker**       | 애플리케이션 컨테이너화 및 환경 일관성 유지  |
| 🔄 **CI/CD**       | Jenkins 및 GitHub Actions로 지속적 통합 및 배포 |

---

## 💡 **배운 점 & 느낀 점**  

1️⃣ **Spring Boot**를 통해 **애플리케이션을 구조화하고 빠르게 개발**하는 방법을 익혔습니다.  
2️⃣ **JPA와 MyBatis**를 사용하여 데이터베이스를 **효율적으로 연동**하고 **관리**하는 기술을 배웠습니다.  
3️⃣ **Spring Security**로 인증 및 권한 관리 기능을 구현하며 **보안의 중요성**을 다시 한번 깨달았습니다.  
4️⃣ **Docker**를 통해 개발 및 배포 환경을 **표준화**하고 팀 협업을 더욱 **효율적**으로 만들었습니다.  
5️⃣ **CI/CD 파이프라인**을 통해 코드의 품질과 배포 자동화를 경험하며 **개발 생산성**을 높였습니다.
