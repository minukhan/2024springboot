# 2024 Spring Boot 프로젝트

## 📖 프로젝트 개요  
이 저장소는 Spring Boot를 활용하여 백엔드 개발을 학습하는 프로젝트입니다. 
RESTful API 개발, 데이터베이스 연동, 보안 설정 등 다양한 백엔드 개발 기술을 실습을 통해 익혔습니다.

---

## 🚀 학습한 기술 스택  
- **Spring Boot**: 빠른 애플리케이션 개발을 위한 프레임워크  
- **JPA**: Java Persistence API를 활용한 데이터베이스 연동  
- **MyBatis**: SQL 매핑을 통한 데이터베이스 연동  
- **Spring Security**: 인증과 권한 부여를 위한 보안 설정  
- **Docker**: 애플리케이션 컨테이너화 및 배포  
- **CI/CD**: Jenkins 및 GitHub Actions를 이용한 지속적인 통합과 배포
